
§3.2 / §3.3 SQL 级 fuzz：每例 1000 个随机数据库

场景                                                   反例数      实测         预期
------------------------------------------------------------------------------------------------
§3.2 A1 正确改写（(cust,yr) 唯一，含 HAVING 与 IS NOT NULL）    0        等价         等价  OK
§3.2 A2 破坏 P2：去掉 HAVING                              722      不等价        不等价  OK
§3.2 A3 破坏 P3：去掉 a IS NOT NULL                       28       不等价        不等价  OK
§3.2 A4 破坏 P1：(cust,yr) 允许重复                         16       不等价        不等价  OK
§3.3 B1 正确改写（pk 唯一，CASE 用 ELSE NULL）                 0        等价         等价  OK
§3.3 B2 破坏 Q2：CASE 用 ELSE 0                          550      不等价        不等价  OK
§3.3 B3 破坏 Q1：promo.pk 允许重复                          11       不等价        不等价  OK

================================================================================================
反例样本（确认 fuzz 抓的是真问题）
================================================================================================

【§3.2 A2 破坏 P2：去掉 HAVING】722/1000 个库结果不同；首个：
      sales = [('c3', 2001, None)]
      Q_lhs -> []
      Q_rhs -> ["('c3', None, None)"]

【§3.2 A3 破坏 P3：去掉 a IS NOT NULL】28/1000 个库结果不同；首个：
      sales = [(None, 2000, 2), ('c2', None, None), (None, 2001, 0)]
      Q_lhs -> []
      Q_rhs -> ['(None, 2, 0)']

【§3.2 A4 破坏 P1：(cust,yr) 允许重复】16/1000 个库结果不同；首个：
      sales = [(None, 2000, None), (None, 2002, -1), ('c2', 2001, 0), ('c2', 2001, 1), ('c2', 2000, 1)]
      Q_lhs -> ["('c2', 1, 0)", "('c2', 1, 1)"]
      Q_rhs -> ["('c2', 1, 1)"]

【§3.3 B2 破坏 Q2：CASE 用 ELSE 0】550/1000 个库结果不同；首个：
      s = [(3, 2), (3, 0), (3, 2), (1, 2)]
      promo = [(1, 'N'), (2, 'N'), (3, 'N')]
      Q_lhs -> ['(None, 6)']
      Q_rhs -> ['(0, 6)']

【§3.3 B3 破坏 Q1：promo.pk 允许重复】11/1000 个库结果不同；首个：
      s = [(2, 2), (3, 2), (2, 1), (None, -1), (None, -1)]
      promo = [(2, 'Y'), (3, 'N'), (2, 'Y')]
      Q_lhs -> ['(6, 3)']
      Q_rhs -> ['(6, 6)']

================================================================================================
结论：
  §3.2 的前提 (a,b) 是 key、HAVING 计数、a IS NOT NULL —— 三者缺一即不等价；
       三者在时 fuzz 找不到任何反例。
  §3.3 的前提 FK->PK（pk 唯一）与 CASE 用 ELSE NULL —— 缺一即不等价；
       两者在时 fuzz 找不到任何反例。
  => 论文说的『规则是条件保序的』在两条规则上都得到了实证。
