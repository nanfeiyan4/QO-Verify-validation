A. 复现 Figure 2 的 memo 结构
==============================================================================
memo Q1     : 6 个 group, 11 个表达式, 隐含 8 棵完整逻辑表达式
  Group 1
      1.1 Get(A)
  Group 2
      2.1 Get(B)
  Group 3
      3.1 Get(C)
  Group 4
      4.1 JOIN[A.x=B.y](G1,G2)
      4.2 JOIN[A.x=B.y](G2,G1)
  Group 5
      5.1 JOIN[B.p=C.q](G2,G3)
      5.2 JOIN[B.p=C.q](G3,G2)
  Group 6  (root)
      6.1 JOIN[B.p=C.q](G4,G3)
      6.2 JOIN[B.p=C.q](G3,G4)
      6.3 JOIN[A.x=B.y](G5,G1)
      6.4 JOIN[A.x=B.y](G1,G5)

把 root group 的 4 条表达式分别展开（显式枚举，仅用于对比规模）：
  #1 JOIN[B.p=C.q](JOIN[A.x=B.y](A, B), C)
  #2 JOIN[B.p=C.q](JOIN[A.x=B.y](B, A), C)
  #3 JOIN[B.p=C.q](C, JOIN[A.x=B.y](A, B))
  #4 JOIN[B.p=C.q](C, JOIN[A.x=B.y](B, A))
  #5 JOIN[A.x=B.y](JOIN[B.p=C.q](B, C), A)
  #6 JOIN[A.x=B.y](JOIN[B.p=C.q](C, B), A)
  #7 JOIN[A.x=B.y](A, JOIN[B.p=C.q](B, C))
  #8 JOIN[A.x=B.y](A, JOIN[B.p=C.q](C, B))
  => 8 棵完整表达式，来自 11 个表达式对象（论文的 compactness 论点）

B. 场景验证
==============================================================================

------------------------------------------------------------------------------
S1  Q1 vs Q1（自身）                              True      True
S2  Q1 vs Q1'（join 顺序不同，语义等价）          Unknown   True

【S2 的命中证据链】
   G6~G6 命中: 6.1 == 6.1
       G4~G4 命中: 4.1 == 4.1
           G1~G1 命中: 1.1 == 1.1
           G2~G2 命中: 2.1 == 2.1
       G3~G3 命中: 3.1 == 3.1

【S3 为什么是 Unknown】两边的 join 谓词集合不同（{A.x=B.y,B.p=C.q} vs {A.x=B.y,A.x=C.p}），
     root group 里不存在签名相同的表达式 → 算法诚实地返回 Unknown，而不是猜测。

==============================================================================
D. 规则集消融：缺规则 -> Unknown，补规则 -> True（覆盖率的真正决定因素）
==============================================================================
  §3.1 场景：Query 2（两个分组子查询 join） vs Query 3（窗口函数）

  --- 规则集不含 §3.1 规则 ---
      QO-Verify => Unknown
      Q2 root 的表达式: ['2.1']
      Q3 root 的表达式: ['3.1']

  --- 把 §3.1 规则加入 Q2 的规则集后 ---
      QO-Verify => True
      G4~G3 命中: RULE.3.1 == 3.1
          G5~G2 命中: F.1 == F.1
              G1~G1 命中: L.1 == L.1

      说明：Q2 的 memo 里出现了一条与 Q3 root 同签名、同结构孩子的表达式
            （RULE.3.1 == 3.1），于是两侧求交成功。
            —— 覆盖率从 0/1 变成 1/1，而算法一行都没改。

==============================================================================
E. 结论
==============================================================================
  1) memo 结构复现成功：6 个 group / 11 个表达式 / 隐含 8 棵完整逻辑表达式。
  2) Algorithm 1 行为与论文一致：
       - S1/S2 返回 True（S2 的初始表达式不同，笨办法只能给 Unknown）；
       - S3 返回 Unknown，且没有误报 True；
       - 匹配是"结构相同"的严格判据（算子 + 谓词 + arity + 有序列孩子）。
  3) 缓存把最坏情况（无命中）的重复比较消掉：见 C 段调用次数对比。
  4) D 段证明：覆盖率是"规则集的函数"，不是"算法的函数"—— 这正是论文 §3 的立论。
